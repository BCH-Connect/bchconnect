BCH Connect supports three protocols: WizardConnect, WalletConnect (using the bch-wc2 specification for Bitcoin Cash) and CashConnect. They are peers. None is privileged in the core; the order the default UI shows them in, WizardConnect first, is a setting you can change.

The protocols genuinely differ, and BCH Connect doesn't paper over that. This page shows where the differences are, so you know what your users will experience with each.

## At a glance

|                            | WizardConnect                                              | WalletConnect                                                              | CashConnect                                                    |
| -------------------------- | ---------------------------------------------------------- | -------------------------------------------------------------------------- | -------------------------------------------------------------- |
| Transport                  | Nostr relay                                                | WalletConnect relay                                                        | Nostr relay                                                    |
| Pairing link               | Ready immediately                                          | Prepared through the relay first                                           | Prepared through the relay first                               |
| Knows the wallet is there  | Yes, from the wallet's ready signal and pings              | No liveness signal; reported as unknown                                    | Yes, from pings                                                |
| Wallet refuses to connect  | The attempt ends as declined                               | The attempt ends as declined                                               | Silence; the attempt keeps waiting unless you set a deadline   |
| User declines a request    | Reported as declined, without saying whether the user or the wallet refused | Reported as declined by the user, when the wallet follows the protocol | Reported as declined, without saying whether the user or the wallet refused |
| Cancelling a request       | The wallet is told and dismisses its prompt                | The wallet is told only if it says it supports cancelling                  | The wallet is told, best effort                                |
| Wallet offline             | Requests wait and are delivered when the wallet returns   | Delivered on reconnect, or times out                                       | Times out; the session shows the wallet as unreachable first   |
| Request expiry on the wire | None                                                       | Required, between 5 minutes and 7 days                                     | Set by the connector; long when you set no deadline            |
| Wrong network              | Detected before the session is established                 | The wallet refuses with its own message                                    | The wallet stays silent                                        |

In every case, cancelling settles the request on your side immediately. What differs is only what the wallet hears about it.

## What this means for your dapp

**Declines are not equally informative.** Only WalletConnect can say for certain that the person declined, and only when their wallet reports it properly. With the other two, treat a decline as "the wallet said no" and word your message accordingly.

**Silence is sometimes an answer.** A CashConnect wallet that declines, or that is on a different network, says nothing. The default UI tells people that if they declined in their wallet, they can close the dialog. If you build your own UI, do the same, or set a deadline for pairing.

**Deadlines are yours to choose.** BCH Connect sets no deadline by default for anything that waits on a person. Where a protocol requires an expiry on the wire, the connector uses a long one, so a very late timeout can still arrive.

## Wallet support

Cashonize supports all three protocols. WalletConnect has the broadest support today, including Selene, Paytaca, Zapit and Electron Cash. CashConnect is still in preview.
