BCH Connect is a wallet-connection library for Bitcoin Cash dapps. Version 0.1.0 is published on npm as an **alpha**: it works, but expect breaking changes before 1.0. These docs are being written.

- Packages: [`@bchconnect/core`](https://www.npmjs.com/package/@bchconnect/core), [`@bchconnect/ui`](https://www.npmjs.com/package/@bchconnect/ui) and [`@bchconnect/connector-walletconnect`](https://www.npmjs.com/package/@bchconnect/connector-walletconnect)
- Source code: [github.com/BCH-Connect/bchconnect](https://github.com/BCH-Connect/bchconnect)
